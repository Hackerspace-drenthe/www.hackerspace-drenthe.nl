# Roboktober

Roboktober is een groot deelnemersproject van Hackerspace Drenthe rond combat robots, workshops en communitybouw. Het platform ondersteunt zowel deelnemers als organisatie met een complete digitale omgeving.

## Projectlinks

- Website: [roboktober.nl](https://www.roboktober.nl)
- GitHub repository: [github.com/Hackerspace-drenthe/www.roboktober.nl](https://github.com/Hackerspace-drenthe/www.roboktober.nl)

## Wat zit er in dit project

- Volledige frontend website
- Backend API en beheerfuncties
- Registratie en contentbeheer
- Designsystem en styling
- Deploy en infrastructuurscripts
- Hardware/electronics documentatie
- Uitgebreide docs en operationele checklisten

## Waarom dit project belangrijk is

- Hoge betrokkenheid van deelnemers en vrijwilligers
- End-to-end open source project onder beheer van Hackerspace Drenthe
- Complete code, documentatie en ontwerpkeuzes publiek in GitHub
