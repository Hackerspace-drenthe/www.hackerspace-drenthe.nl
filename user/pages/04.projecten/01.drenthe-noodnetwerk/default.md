# Drenthe Noodnetwerk

Drenthe Noodnetwerk is een van de grootste communityprojecten van Hackerspace Drenthe, met veel deelnemers uit de regio. Het project bouwt aan een robuust mesh-netwerk voor communicatie, documentatie en praktische inzet.

## Projectlinks

- Website: [drenthenoodnetwerk.nl](https://drenthenoodnetwerk.nl)
- GitHub repository: [github.com/Hackerspace-drenthe/www.drenthenoodnetwerk.nl](https://github.com/Hackerspace-drenthe/www.drenthenoodnetwerk.nl)

## Wat zit er in dit project

- Volledige website en informatieplatform
- Design en UI-assets
- Technische documentatie en handleidingen
- Interactieve tools en planners
- MeshAcademy content en cursusmateriaal
- Presentaties en communicatie-assets

## Waarom dit project belangrijk is

- Groot bereik binnen en buiten de hackerspace
- Sterke focus op praktische toepasbaarheid
- Open samenwerking via GitHub met complete projecthistorie
