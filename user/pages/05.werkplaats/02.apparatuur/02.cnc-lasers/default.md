# CNC-lasers

De plattegrond markeert hier het CNC-lasergebied. De BRM 90130 is geschikt voor snijden en graveren; de Laserbox is een desktop-lasersnijder.

- [BRM-lasersnijder: handleiding, training en veiligheidsstappen](/werkplaats/apparatuur/cnc-lasers/brm-lasersnijder)

Volg de benodigde instructie voordat je een machine zelfstandig gebruikt. Blijf tijdens het lasersnijden bij de machine; materiaal kan vlam vatten.
